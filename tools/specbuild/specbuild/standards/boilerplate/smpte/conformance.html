3 Conformance

Normative text is text that describes elements of the design that are indispensable or contains the conformance language keywords: "shall", "should", "may", "can", "will", "is required to", "is strongly recommended", "is recommended", "is permitted to", "is not required to", and "is not recommended". Informative text is text that is potentially helpful to the user, but not indispensable, and can be removed, changed, or added editorially without affecting interoperability.

Informative text does not contain any conformance keywords. All text in this document is, by default, normative, except for sections explicitly labeled as "Informative" or individual paragraphs that start with "Note:".
